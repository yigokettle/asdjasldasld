## 最终结论

### 问题二

问题二可独立选择时间优先的 23 架次方案：80 箱全部按期，最晚运输返航 6569 s，总运输能耗 71.3885 kWh。22 架次方案作为能耗和架次对照：最晚返航 6899 s，能耗 63.541585 kWh。

### 问题三

采用 22 个运输架次和 4 个中继架次。80 箱全部交付，最后货箱 6227 s 送达，运输完成 6899 s，中继完成 6936 s，联合完成时间 6936 s，总能耗 66.215521 kWh。精确通信核验中断累计为 0 s，R01/R02 两架中继无人机和 6 组能源组件约束通过。

### 问题四

严格继承问题三的运输、通信和逐箱时刻。原题允许的分区全部枚举后：若只最小化库存缺口，2 组单站方案缺口最低为 4 件；若要求每个独立组至少 2 个服务区，唯一结构为 S001、S006 与其余 13 区，但缺口为 10 件。允许独立组复制完整中继模板时，推荐 2 组 8/7 区方案，缺口 5 件，运输工时 Gini 0.0530，总能耗 68.710272 kWh。

## 论文使用注意

1. 问题二可以独立优化，不要求继承问题一或问题三；问题四必须继承问题三最终方案。
2. “固定路线调度最优”只表示固定候选路线、实体分配和访问顺序下的 CP-SAT 最优，不等于完整路线选择空间的全局最优。
3. 普通货箱期望时间在本项目中作为零延误强化目标，题目明确的医疗和首批截止仍应单独报告为硬约束。
4. 问题四的中继复制属于独立执行的增配情景，必须与严格冻结中继任务不复制的结果分开表述。
